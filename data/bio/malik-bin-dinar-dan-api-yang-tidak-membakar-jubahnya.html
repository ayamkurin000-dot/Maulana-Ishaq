Kisah Karamah — Api — Jubah Wol — Bashrah Terbakar

1. RINGKASAN KISAH

Kisah karamah Malik bin Dinar — api besar di Bashrah tidak membakar jubah wolnya saat ia menyelamatkan tetangga. Karamah

2. URAIAN KISAH

Pasar Bashrah terbakar hebat. Orang-orang berlarian. Malik masuk ke tengah api untuk menyelamatkan seorang nenek lumpuh yang terjebak.

Orang berteriak: "Malik akan terbakar!" Tapi ia keluar menggendong nenek itu, jubah wolnya tidak terbakar sedikit pun, hanya berbau asap.

Ditanya: "Bagaimana bisa?" Malik berkata: "Api dunia takut pada orang yang takut pada api akhirat." Riwayat karamah — Hilyat al-Awliya', Karamat al-Awliya'

3. HIKMAH

Barangsiapa takut api neraka, api dunia pun segan menyentuhnya.
